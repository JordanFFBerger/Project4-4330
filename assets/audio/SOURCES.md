# Pokémon cries

The 13 recordings are the `latest` game cries from the community-maintained
[PokéAPI cries repository](https://github.com/PokeAPI/cries), downloaded 2026-10-02.
Source pattern: `https://raw.githubusercontent.com/PokeAPI/cries/main/cries/pokemon/latest/{national-pokedex-id}.ogg`.
IDs match `assets/pokemon/manifest.json`. Files are bundled for offline playback.
The upstream `25.ogg` contains MPEG audio; it is stored as `25.mp3` to match its actual format. The other twelve files are Ogg Vorbis.
Pokémon names and recordings belong to their respective rights holders; the
repository's code license does not grant ownership of the underlying game assets.
